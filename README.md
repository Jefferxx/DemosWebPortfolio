# DemosWebPortfolio

Landing pages de demostración por nicho — Riobamba, Ecuador.

Demos desplegadas en GitHub Pages: `https://jefferxx.github.io/DemosWebPortfolio/`

| Demo | Nicho | URL | Estado |
|---|---|---|---|
| [demo-clinica-v2](demo-clinica-v2/) | Clínica médica (MEDICGAR) | `/demo-clinica-v2/` | ✅ Live |
| [demo-campus](demo-campus/) | Cafetería / Pub híbrido (Campus Coffee & Beer) | `/demo-campus/` | ✅ Live |

Construidas con HTML5 + CSS3 + Vanilla JS. Mobile-first. PageSpeed 85+.

## Stack técnico

- HTML5 semántico
- CSS3: Custom Properties, Grid, Flexbox, animaciones `@keyframes`
- Vanilla JS: IntersectionObserver, tabs, lightbox modal
- Google Fonts: Bebas Neue + Pacifico + Outfit
- Sin dependencias externas, sin frameworks
